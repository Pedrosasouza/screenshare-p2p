# Demonstração Visual (Preview / Demo)

Coloque aqui uma captura de tela (`preview.png`) ou um GIF animado (`preview.gif`) do StreamGrid em funcionamento.

### Sugestão de captura:
1. Abra duas abas no navegador ou dois computadores na mesma sala do StreamGrid.
2. Inicie o compartilhamento de tela em ambos.
3. Tire um print mostrando a **grade com as duas telas ativas** e os controles de volume.
4. Salve como `preview.png` nesta pasta (`docs/preview.png`).

O `README.md` já está configurado para exibir essa imagem automaticamente no topo!
